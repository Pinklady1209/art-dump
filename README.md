# Art Dump
A HTML & CSS website for art and doodles.

[Click here to take a look!] --> (https://pinklady1209.github.io/art-dump/)

![Alt text](art-peices/READMEphoto.png)

## Features
    - Just random people/creatures
    - Caption bubble next to each image
    - Lesbian flag colour scheme
    - Hand drawn (by me) pfp in top right corner
    - Info on how the art has been made
    - Link to contact me on Slack
    - Rules for art bounties

## Running on your own

Download the project files and open up `index.html`!
